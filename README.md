# Monte Alto, rua por rua

Apresentação interativa do Projeto de Urbanização de Monte Alto, Arraial do Cabo/RJ:
pavimentação (paralelepípedo e intertravado) e drenagem pluvial das ruas José Maria Rosa,
da Alegria, da Liberdade, Por do Sol, das Flores e da Amizade.

- Planta das ruas em escala, com norte para cima, a partir das pranchas do projeto.
- Toque numa rua para ver o que o projeto prevê e abra a rua em 3D.
- Funciona no navegador do celular ou do computador; precisa de internet só para carregar o three.js.

Elaborado por Construgarden Construtora e Empreendimentos.

## Publicar no GitHub Pages

1. Envie `index.html`, `.nojekyll` e este `README.md` para a raiz de um repositório da Construgarden.
2. Em Settings > Pages, escolha "Deploy from a branch", branch `main`, pasta `/ (root)`.
3. O endereço fica `https://<usuario-ou-organizacao>.github.io/<repositorio>/`.
